Comment utiliser cet outil ?

1. Menu Latéral

Le menu à gauche vous permet d'accéder à toutes les listes et tous les graphiques.

2. Problème d'affichage ?

Si la base de données semble vide ou bloquée, cliquez sur l'icône ⚙️ (Paramètres) en bas du menu de gauche, puis cliquez sur le bouton rouge "Réinitialiser la base de données".
